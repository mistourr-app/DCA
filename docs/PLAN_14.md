# План пункта 14: интеграция в Defold

Цель: игра запускается в редакторе, на экране видно поле из окна рядов, ход тапом по клетке, лагерь, смерть и сохранение работают. Логика уже в `core/`, здесь только связка с движком.

Порядок подпунктов фиксирован. Каждый подпункт: код, тесты `luajit tests/run.lua`, коммит, push.

## 14.1 Ход игрока: `core/run.lua`
- Шаги GDD §5.2: проверка хода (`movement.options`), атака «в спину», смерть, перемещение, подбор клеток (золото, лечение), смена ряда (`equipment.new_row`), тик перезарядки.
- Возвращает список событий (`{ type = "move" | "gold" | "heal" | "behind_attack" | "death" | "refused", ... }`) для скрипта. Ядро не знает про Defold.
- Тесты: `tests/core/run_test.lua`.
- Заодно: `world.move` разрешает любой столбец следующего ряда, стоимость HP проверяет `movement`.

## 14.2 Ближний бой и выстрел в `core/run.lua`
- Клик по врагу на следующем ряду: `combat.melee`, смерть врага, удаление из клетки.
- Выстрел по месту: `equipment.fire`, `combat.shot`, один выстрел за ряд.
- Тесты: бой, смерть врага, смерть игрока, выстрел без ответа.

## 14.3 Заглушки на экране: `world.collection`
- Контейнер рядов, `cell` (game object), `player` (game object), `enemy` (game object).
- Вид: встроенный спрайт Defold `/builtins/graphics/particle_blob.png` с окраской через `go.set("#sprite", "tint", ...)`, цвета из GDD §12. Своих ассетов нет (решение по этапу прототипа).
- Окно рядов: `core/world.window`, объекты создаются при входе в окно и удаляются при выходе.

## 14.4 Ввод: `scripts/input.lua`
- Экранная точка (тап) → колонка и ряд поля. Ввод `touch`, `action.pressed`.
- Чистая функция пересчёта координат вынесена в `core/layout.lua`, тестируется.

## 14.5 Скрипт мира: `collections/world.script`
- Вызывает `core/run`, проигрывает события: анимации (`anim.*`), обновление HUD.
- Блокирует ввод на время хода (флаг).

## 14.6 Экраны лагеря и смерти
- `gui/camp.gui` и `gui/death.gui`: кнопка «Разбить лагерь» с ценником (процент от золота), кнопка «Вернуться» на экране смерти.
- Вызывают `core/camp` и `core/death`.

## 14.7 Сохранения: `scripts/saves.lua`
- `sys.save` / `sys.load` через `core/save_schema`. Сохранение при установке лагеря, при прохождении чекпоинта, при уходе в фон.
- Открытый вопрос GDD §20 (восстановление сессии) на этом шаге не решается: сначала сохраняем точку возврата.

## 14.8 Проверка
- Build в редакторе 1.14.0 без ошибок и без предупреждений о ресурсах.
- Лог запуска без `ERROR`.
- На экране видно поле 5 колонок, ход тапом по клетке работает, смерть и возврат работают.
