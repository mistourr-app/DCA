# План работ

Порядок пунктов фиксирован. Пункт начинается после завершения предыдущего. Значения, помеченные TBD, решаются после первой сборки (см. пункт 17).

1. Каркас: `game.project`, `main/`, `collections/`, `balance/balance.csv` (снимок из DR без бонусов, патронов и кампании).
2. `tools/build_balance.py`: генерация `core/data/balance.lua`, режим `--check`. Отказ на значениях TBD.
3. `tests/run.lua` и `tests/registry_test.lua`.
4. Проверка: `build_balance.py --check`, `lua tests/run.lua`, сборка в Defold 1.14.0 без ошибок.
5. Ядро с тестами: `rng`, `row_seed`, `grid`, `visibility`, `combat`.
6. `row_gen`: обычный ряд, ряд чекпоинта, ряд босса.
7. `world`: окно рядов, режимы WORLD / CAMP / BOSS / DEATH, точка возврата.
8. `journal` и тест памяти.
9. `camp`: установка за процент золота, оплата за N ходов.
10. `death`: возврат в лагерь (с восстановлением) или в чекпоинт (без него).
11. `equipment`: заряды и перезарядка (арбалет).
12. `upgrades` (5 треков) и `save_schema`.
13. `registry/*`: клетки, враги, экипировка, боссы, типы рядов.
14. Интеграция в Defold: `world.collection`, заглушки `cell`, `player`, `enemy`, ввод, `camp.gui`, `death.gui`, сохранения.
15. Бой с боссом: арена, `boss_default`, чекпоинт после победы.
16. Тест памяти на 2000+ рядов, профилирование, сборка для Android.
17. Значения TBD в CSV после первой сборки: K, N восстановления, процент и ходы оплаты, кривые сложности.
18. Поведение конкретных боссов.
19. Туториал (отложен).
20. Бэклог: NPC, торговцы, ловушки, сундуки, лут с боссов, телепорт.
