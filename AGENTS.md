# AGENTS.md

Точка входа для ИИ-агентов. Прочитай это до первой правки, дальше — `docs/AI_CODING_RULES.md` целиком.

## Главное правило: юзер-центричность

Владелец настраивает игру в редакторе Defold, а не в коде. Всё, что можно покрутить (цвет, размер, длительность, отступ, текст, скорость), обязано быть видно и меняться в инспекторе. Код — только для того, чего редактор не умеет представлять. Подробно — `docs/AI_CODING_RULES.md` §0.

Проверка перед сдачей: открой проект в Defold, найди параметр в инспекторе и измени его, не трогая `.lua`/`.script`. Не нашёл — задача не сделана.

Единственное исключение — порядок z: структурная константа, живёт в `scripts/view/layers.lua` и защищена `tests/view/layers_test.lua`.

## Обязательный минимум

- Движок: **Defold 1.14.0**. API сверять с manual этой версии, ничего не выдумывать.
- Логика — в `core/` (чистый Lua, без Defold API). `.script`/`.gui_script` — только связка.
- Числа правил — `balance/balance.csv`, числа для `core/` — `design/design.csv`; оба генерируются (`python tools/build_balance.py`).
- Цвета палитры — узлы `gui/palette.gui` (пикер в GUI-редакторе), не числа в скриптах.
- Тексты в игре — только английский. Комментарии, документация, тесты — русский.
- Не коммитить без явной просьбы владельца.

## Перед сдачей

```
luajit tests/run.lua
python tools/check_requires.py
python tools/check_defold_files.py
python tools/build_balance.py --check
```

Сборку и загрузку коллекций проверять в редакторе 1.14.0: лог без `ERROR`, ручной запуск (F5). Правки `.script`/`.gui_script` дополнительно проверяются запуском собранного проекта без редактора (`bob` + `dmengine`, `docs/TESTING.md` §8): `run.err` пуст — скрипты стартуют, `ERROR:SCRIPT` со стеком — виден там же.
